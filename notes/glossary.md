# Glossary

| Term | Meaning |
|---|---|
| Order | What a customer placed. Has one or more lines. |
| Order line | One product and a quantity, on one order. |
| Shipment | One parcel. An order may produce several. |
| Dispatch | The moment a shipment leaves the warehouse. |
| Return request | A customer asking to send goods back. |
| Refunds clerk | The role allowed to approve a refund. |
